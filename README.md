## 🎯 What is EnteraPay?

EnteraPay is a creator-economy platform that lets:
- 🎥 **Creators** — upload and monetize films, songs, videos
- 💼 **Managers** — manage talent, contracts, and royalties
- 🤝 **Sponsors** — discover and fund content
- 💰 **Investors** — invest in entertainment projects and earn returns
- 🎵 **Fans** — pay for content, subscribe, and support creators

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend API | NestJS + TypeScript |
| Database | PostgreSQL + Prisma |
| Cache | Redis |
| Storage | Cloudflare R2 / AWS S3 |
| Streaming | Mux / Cloudflare Stream |
| Frontend | Next.js + Tailwind CSS |
| Payments | Stripe Connect |
| Auth | JWT / Auth.js |
| DevOps | Docker + GitHub Actions |
